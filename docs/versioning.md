# Версионирование скиллов

## Единица версии

8 скиллов toolkit выпускаются как один согласованный комплект с общей версией MAJOR.MINOR.PATCH. Версия охватывает SKILL.md, входящие в скиллы метаданные, справочники и шаблоны, а также совместимые с ними корневые профили agents/. Публичные имена и пути не содержат версию; независимые версии скиллов и диапазоны зависимостей не вводятся.

Единственный номер выпуска находится в [CHANGELOG](../CHANGELOG.md). Последний выпуск задаёт верхняя числовая запись журнала; ещё не выпущенные изменения находятся в Unreleased. README ссылается на журнал и не дублирует номер.

## Выбор следующего номера

Контракт скилла — условия применения, обязательное поведение, полномочия ролей, входы и результаты, форматы передачи и обязательные зависимости. Совместимость означает, что ранее допустимый сценарий потребителя остаётся допустимым без адаптации.

| Изменение | Номер |
|---|---|
| Несовместимое изменение контракта | MAJOR + 1, остальные — 0 |
| Совместимое расширение | MINOR + 1, PATCH — 0 |
| Исправление в пределах существующего контракта | PATCH + 1 |

Для нескольких изменений выбирай наибольший требуемый уровень. До выпуска изменения остаются в Unreleased; commit, тег и публикация создаются только при прямом разрешении. Для точного импорта сохраняй commit либо manifest проверенного незакоммиченного снимка по [project-local](project-local.md): номер описывает совместимость, а точные байты устанавливает снимок.
