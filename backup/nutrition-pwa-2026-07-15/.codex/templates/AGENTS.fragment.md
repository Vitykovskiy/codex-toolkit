# Фрагмент `AGENTS.md`

Скопируйте блок в корневой `AGENTS.md`. Пути внутри блока разрешаются от корня проекта.

```markdown
## Агентская оркестрация

- По умолчанию корневой агент самостоятельно выполняет обычные задачи типов answer, diagnose, change, review и build.
- Активируй оркестрацию по явному запросу пользователя на оркестрацию, делегирование или параллельную агентскую работу, по требованию применимого обязательного skill или `AGENTS.md`, либо для задачи класса `complex`.
- После активации читай [`.codex/complex-task-orchestration.md`](.codex/complex-task-orchestration.md), применяй роли из `.codex/agents/`, классифицируй задачу как `simple`, `focused` или `complex` и соблюдай утверждённый маршрут, `max_depth = 1`, лимит четырёх потоков и непересекающиеся разрешённые списки файлов.
- В активированной оркестрации корневой агент работает диспетчером: предметный анализ, реализацию, ревью и проверки выполняют назначенные подагенты.
- Постоянные материалы `.codex` входят в основной Git-контекст; временные артефакты в `.codex/tmp/` игнорируются. Commit, push и PR выполняй только после явного разрешения пользователя.
- При заполнении контекста действуй по [`.codex/continuity/create-handoff.md`](.codex/continuity/create-handoff.md); новую сессию восстанавливай по [`.codex/continuity/resume-orchestration.md`](.codex/continuity/resume-orchestration.md).
- Рабочие карточки, отчёты и handoff храни в игнорируемом `.codex/tmp/tasks/<task-id>/` по шаблонам `.codex/templates/`.
```
