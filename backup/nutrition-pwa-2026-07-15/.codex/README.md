# Конфигурация Codex

`.codex` хранит постоянные проектные пакты, профили ролей, шаблоны и инструкции продолжения работы. Каталог отслеживается основным Git-репозиторием.

Временные карточки задач, handoff, логи, кэш, локальные настройки и секреты хранятся только в `.codex/tmp/` и игнорируются корневым `.gitignore`.

## Оркестрация

Обычные задачи выполняет корневой агент. Оркестрация включается только по явному запросу пользователя, обязательному skill/инструкции или для задачи класса `complex`; порядок задан в [complex-task-orchestration.md](complex-task-orchestration.md). Профили в `agents/` сами её не запускают.

При заполнении контекста используй `continuity/create-handoff.md`; для восстановления — `continuity/resume-orchestration.md`. Рабочие артефакты создавай в `.codex/tmp/tasks/<task-id>/` по `templates/`.
