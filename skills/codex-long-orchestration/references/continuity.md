# Continuity

Resume only from one current `dispatcher_only` state, its referenced source revision, and the accepted evidence. Keep completed reports immutable. Reconcile recorded active handles with native status, restore queued transitions and resource reservations, then continue permitted ready work under [Parallel execution](../../codex-orchestration-pact/references/parallel-execution.md). Do not duplicate running or accepted assignments or read any subject file/report, excerpt or summary into root. Resume only the dispatcher's own compact process state.

For resumed subject work, forward only unchanged original source references, role/basic instruction, task root and task/assignment/dependency identifiers under [Project requirements](../../codex-orchestration-pact/SKILL.md#project-requirements). The recipient independently locates and reads original sources and predecessor artifacts, formulates and records its own working task under the [dispatcher invariant](../../codex-orchestration-pact/SKILL.md#dispatcher-invariant); unchanged current rules need no new scout. Recheck only rules affected by changed scope, source text or uncommitted edits, preserving unaffected accepted results.

State tracks pending transitions, active identities/handles and launch revisions, dependency receipts and bound snapshots, resource reservations, checkpoint, accepted packet members, current plan revision/completion aggregate, process signal, and known cost increments. Unknown usage or telemetry remains `unknown`, never zero; an unset user limit remains `not_set` and missing completion metadata remains `null`. No new budget agreement is required on resume. Root copies envelope fields without interpreting the subject report and preserves them across resume. Apply [Progress and efficiency](../../codex-orchestration-pact/SKILL.md#progress-and-efficiency) to stalls, repetition, excessive verification and plan/goal drift: the existing owner prepares the correction and any revised estimate from unchanged original source references. Resume retains current accepted work and does not itself reset the denominator or trigger repeated checks. Root records only routing metadata.

A state or envelope with a superseded assignment revision, missing report, unsafe path, unsupported sender, or unresolved required capability is not resumed as successful. Preserve the exact limitation and request the smallest necessary owner action; independent ready work may continue. Apply only owner-identified invalidations. A cancellation request or missing handle is not proof that an old writer stopped; retain its resource reservation until native status resolves the ambiguity. Legacy single transitions are normalized by the [state contract](templates/state.md), without restarting completed work.

Bound model work using [Model and reasoning selection](../../codex-orchestration-pact/SKILL.md#model-and-reasoning-selection) and the existing artifacts, not another state system. Preserve original messages and ordered corrections, assignments, current evidence and acceptance across context changes. Replacement owners read the relevant authoritative sources and dependencies before resuming their unfinished work. File existence is not proof of freshness or reading; an API context specification is not proof of the effective subscribed-client window or perfect recall. Ordinary continuity remains lightweight; task length alone does not activate this strict procedure.
