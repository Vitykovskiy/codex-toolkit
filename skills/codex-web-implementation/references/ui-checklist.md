# Чек-лист реализации UI

Читайте этот чек-лист для изменяемого пользовательского сценария, когда нужны подробные критерии интерфейса. Основная процедура находится в [SKILL.md](../SKILL.md).

## Согласованность сценария

- Требование, дизайн и фактические данные не противоречат друг другу; существующие компоненты и токены применены там, где они уже покрывают задачу.
- Элемент имеет семантику, соответствующую действию: кнопка выполняет действие, ссылка ведёт к ресурсу, поле связано с понятной подписью.
- После действия пользователь видит понятный эффект: новое состояние, подтверждение, ошибку или следующий шаг.

## Ввод и состояния

- Поля имеют доступное имя, понятную подсказку при необходимости и сообщение валидации, связанное с причиной ошибки.
- Управление фокусом предсказуемо после открытия, отправки, ошибки и закрытия изменённого состояния; весь сценарий доступен с клавиатуры.
- Загрузка, пустой результат, ошибка и повтор не скрывают данные или уже введённый текст без установленного правила.
- Длинный, локализованный и пустой контент не обрезает смысл и не делает действие недоступным.

## Размер и проверка

- Затронутый сценарий остаётся пригодным на целевых размерах экрана; порядок и видимость элементов не мешают действию.
- Проверяйте только применимые пункты. Не меняйте оформление остальных экранов ради прохождения чек-листа.
