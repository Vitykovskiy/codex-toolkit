# Подключение процедур

Подключай skill по ситуации: разработку для изменения кода, документацию для устойчивых текстов, UI-анализ для анализа интерфейса и оркестрацию для зависимых или параллельных назначений. Прочитай основную процедуру выбранного skill; справочники открывай только по её условной ссылке.

Для длительной передачи оркестрации используй continuity-инструкции и состояние `.codex/tmp/tasks/<task-id>/`, если этот путь применим в проекте. Этот фрагмент не задаёт структуру продуктового репозитория.
