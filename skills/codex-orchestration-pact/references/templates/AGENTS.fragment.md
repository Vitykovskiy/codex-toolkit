# Фрагмент `AGENTS.md`

Скопируйте блок в корневой `AGENTS.md`. Пути внутри блока разрешаются от корня проекта.

```markdown
## Агентская оркестрация

- По умолчанию корневой агент самостоятельно выполняет обычные задачи типов answer, diagnose, change, review и build.
- Активируй оркестрацию по явному запросу пользователя на оркестрацию, делегирование или параллельную агентскую работу, по требованию применимого обязательного skill или `AGENTS.md`, либо для задачи класса `complex`.
- После активации применяй skill `codex-orchestration-pact`, классифицируй задачу как `simple`, `wide_mechanical`, `focused` или `complex` и соблюдай утверждённый маршрут. Параллельность ограничивают доступная ёмкость среды, зависимости, пересечение `write-set` и конфликтующие ресурсы; фиксированного числового лимита нет.
- В активированной оркестрации root работает только диспетчером и конечным автоматом: хранит дословные цель и ограничения, назначает роли, передаёт ссылки и контролирует статусы, зависимости и шлюзы. Предметный анализ, решения, декомпозицию, реализацию, ревью и проверки выполняют владельцы ролей.
- Постоянные материалы `.codex` входят в основной Git-контекст; временные артефакты в `.codex/tmp/` игнорируются. Commit, push и PR выполняй только после явного разрешения пользователя.
- При заполнении контекста и возобновлении используй continuity-инструкции skill `codex-orchestration-pact`.
- Рабочие карточки, отчёты, Decision Log и handoff храни в `.codex/tmp/tasks/<task-id>/` по каноническим шаблонам skill.
```
