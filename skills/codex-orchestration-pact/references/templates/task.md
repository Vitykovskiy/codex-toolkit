# Назначение

Decomposer оформляет точное назначение до исполнения; root передаёт путь без реконструкции предметного тела. Обычное поручение содержит ID, роль и профиль, дословную цель либо её путь, входы, точный `write_set`, критерии, проверки, зависимости/общие ресурсы, собственный `artifact_path` и единственный допустимый следующий шаг. `write_set: []` разрешает только анализ и собственный отчёт. Недостающий необходимый файл требует пересмотра назначения до записи.

Для dispatcher-only применяй ровно нужный краткий вариант; результаты создают сами назначенные роли, а не заглушки:

| Вариант | Обязательные входы и результат |
|---|---|
| `intake` | Дословные пользовательские источники/вложения; analyst может начать без `goal`, создаёт назначенную версию goal. |
| `decompose` | Goal, принятые решения и наблюдения; decomposer оформляет назначения текущей партии. |
| `review` | Исходное назначение, результат/снимок и отчёт исполнителя; независимый reviewer проверяет критерии. |
| `fix` | То же назначение, устойчивые finding ID и новая попытка; исполнитель исправляет только прежний `write_set`. |
| `consult` / `escalate` | Один точный вопрос, назначенный профиль и новые существенные факты/различающая проверка; роль возвращает решение или недостающий вход. |
| `revalidate` | Активное назначение и извещение об изменении; владелец устанавливает влияние и узкие необходимые проверки. |

`task_root` — явно установленный локальный якорь; пути задачи безопасно разрешаются внутри него, а исходный `write_set` относится к явно названному Git-контексту. Изменение цели, решения, критериев или write-set создаёт заменяющее назначение и требует независимой проверки затронутой ревизии. Роль не делегирует, атомарно пишет полный [отчёт](report.md) и возвращает root только [краткое извещение](../../../codex-long-orchestration/references/templates/envelope.md).
