# Orchestration reference

Use the smallest route that preserves the stated outcome. The canonical portable route table is in the parent [orchestration pact](../SKILL.md#portable-route-table), not in a toolkit-root file that a consumer does not import. A ready specification is assigned directly; neither an analyst nor decomposer rephrases it. A clear connected behaviour change is one developer plus one independent reviewer. Truly independent responsibilities may use at most two concurrent writers, then one packet review. A material decision gets one architect consultation that may also prepare executable assignments and write-sets.

`scout` gathers narrow facts, `analyst_standard` investigates one unknown, `architect` chooses a material decision, `decomposer` remains an explicitly invoked standalone compatibility role, `mechanical` applies literal edits, and `developer` changes behaviour. `reviewer_fast` reviews only provably literal non-semantic edits. `reviewer` performs normal independent review. `integration_reviewer` replaces it for a named cross-part or security concern. `analyst`, `architect_astra`, and `quality_owner_astra` require a direct applicable user authorization; availability, complexity, retry, or resume does not grant it.

One sufficient independent review checks requirements, implementation, related risk, and relevant links. Do not add a final reviewer of other reviewers. A packet reviewer records an acceptance entry for every completed result; each packet entry has its exact assignment, attempt, goal version, and snapshot. No self-approval, duplicate/stale item, incomplete result, or missing evidence is valid. A normal fix remains with its owner and is reviewed only for the fix, affected dependencies, and regressions.

Use strict dispatcher only for explicit durable state. Roles do not launch roles. In ordinary mode an owner returns outcome, changes, checks, material risk, and next action. In strict mode the owner writes the full report and returns an envelope; root operates process state without technical acceptance.
