# Intake исходного запроса

Для широкой задачи root сохраняет оригиналы сообщений и вложений по порядку как `U001`, `U002` и далее, не пересказывая их предметно. Для файлового входа фиксируй источник копии, доступность оригинала и hash только как отпечаток копии; `missing` не выдавай за сверенный оригинал.

Analyst создаёт версию goal: каждое существенное требование связано с ID источника; противоречия, неизвестности, допущения и предложения остаются отдельными. Поздняя инструкция меняет только относящиеся пункты и указывает источник; предыдущая используемая версия сохраняется. Analyst не выбирает архитектуру, write-set или код. Если вопрос действительно нужен, он спрашивает решение, а не инструменты.

```yaml
goal_version: 1
sources: [U001]
requirements: []
contradictions: []
unknowns: []
next_subject_owner: decomposer
```
