# Синтетическое чтение

Документ: «Одна коробка содержит 12 деталей. Две коробки содержат 24 детали».
Задание исполнителя: проверить арифметику без изменения этого README, создать новый UUID посредством Python uuid.uuid4() и сохранить его с выводом только в result.evidence собственного отчёта. Этот идентификатор служит номером проведённой проверки. Проверяющему передаётся путь отчёта. Разрешены только назначенные процессные артефакты.
