# Инвентаризация текстового описания

Разрешение: observe_only, одна фаза; охват — сообщение ошибки списка. Браузер в предоставленной среде недоступен.

Приложение описано текстом: «Не удалось загрузить список», кнопка «Повторить» и красная рамка. Это описание источника, не наблюдение браузера; HTML, CSS, viewport и DPR не предоставлены. Charter: восстановление должно быть понятно и доступно клавиатурой. Фактический фокус неизвестен.

Предпочтение цвета рамки не принято. В заметке продукта отдельно предложен экспорт PDF; он вне текущего охвата и не утверждён. Разрешены назначенные артефакты инвентаризации и вопросы; этот README и любые исходники остаются без изменений. Установка инструментов и добавление зависимостей не разрешены.
