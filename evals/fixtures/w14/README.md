# Синтетический экран списка

Приложение — index.html, без зависимостей и внешнего API. Запуск: python3 -m http.server 8000 --bind 127.0.0.1 из каталога проекта; открыть локальный index.html. Если порт занят, выбрать свободный и записать адрес.

Charter проекта, принят для этой задачи, версия 1:
- В одном контексте ошибки пользователь видит понятное сообщение и одно основное действие восстановления. Технический код остаётся доступен в подробностях.
- Повторные элементы одного маршрута допустимы лишь с обоснованным отличием сценария; доступ к списку сохраняется.
- Восстановление доступно клавиатурой, результат «Готово» объявляется пользователю; фокус не теряется.
- Проверяемые размеры: 390 × 844 и 1280 × 800 CSS px. Страница не имеет горизонтального переполнения.

Начальное состояние — ошибка синтетической загрузки. Нажатие любой кнопки «Повторить» меняет сообщение на «Готово». Это контролируемая локальная имитация, не серверная интеграция. Разрешён improve в index.html для одной связанной партии до трёх изменений без новых функций/API/зависимостей. Остальные находки сохраняются кандидатами. Предпочтения по цвету и стилю не заданы.
